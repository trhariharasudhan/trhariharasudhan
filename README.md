## 👨‍💻 About Me

I'm an **Independent Developer** focused on building practical software systems
around **AI, automation, backend development, and developer tooling**.

My background as an **IT Support Engineer** gave me hands-on experience with
technical troubleshooting, hardware and software diagnostics, system issue
resolution, networking fundamentals, and customer coordination.

Today, I'm applying that systems-oriented mindset to software development —
building projects, experimenting with local AI, designing backend architectures,
and continuously learning through real-world implementation.

### What I Do

- 🤖 Build **local AI assistants** and AI-powered developer tools
- ⚡ Design **automation workflows** for repetitive tasks
- 🔧 Develop **Python & FastAPI backend systems**
- 🧠 Experiment with **RAG, vector search, embeddings, and local LLMs**
- 🐳 Work with **Docker, PostgreSQL, Linux, and API-based architectures**
- 🌐 Build **browser extensions and productivity tools**
- 🔒 Explore **systems, networking, and security fundamentals**

> **My approach:** Learn by building, solve real problems, and improve one system at a time.
