## Featured Projects

### Grandpa AI Assistant

A local Windows AI assistant designed for voice interaction, application control, screen automation, and productivity workflows.

**Technologies:** Python, Faster Whisper, Ollama, Windows Automation, Local AI

### ChronoBot

A retrieval-augmented AI assistant with document upload, semantic search, streaming responses, and hallucination protection.

**Technologies:** FastAPI, React, FAISS, RAG, Python, REST APIs

### FocusFlow for YouTube

A Chrome extension that transforms YouTube into a focused learning workspace with transcripts, notes, summaries, flashcards, quizzes, and AI-powered study tools.

**Technologies:** JavaScript, Chrome Extensions, IndexedDB, Ollama, OpenAI API, Gemini

### MotoCompass

A biker-focused application concept for private ride rooms, rider tracking, route planning, SOS features, and ride history.

**Technologies:** Flutter, FastAPI, PostgreSQL, Maps APIs, Real-Time Systems
